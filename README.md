## Overview

Built with a focus on visual storytelling and fast load times, this site serves as the primary online storefront and portfolio for Sood Photography. The layout prioritizes high-resolution imagery, clean typography, and frictionless inquiry flows.

## Key Features

- **Responsive Portfolio Gallery:** Adaptive grid layout engineered for seamless viewing across widescreen displays, tablets, and mobile devices.
- **Category Filtering & Lightbox Preview:** Organized collections (Weddings, Portraits, Events, Commercial) with distraction-free full-resolution viewing.
- **Service & Package Showcase:** Clear presentation of studio offerings, deliverables, and booking workflows.
- **Client Inquiry Integration:** Direct booking and contact flow for prospective clients.
- **Performance Optimization:** Lazy-loaded media and lightweight assets for fast initial page loads.
